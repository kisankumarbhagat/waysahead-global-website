# WaysAhead Global Website – Backend Assignment Submission

This repository contains the backend for the WaysAhead Global website, built using Node.js, Express.js, and MongoDB. It provides secure REST APIs for job listings, contact form submissions, news updates, and chatbot interactions.

## Features

- **Job Listings API:** Retrieve dynamic job data.
- **Contact API:** Handle contact form submissions with email notifications.
- **Chatbot Integration:** Supports FAQ responses and navigation assistance.
- **Error Handling & Security:** Proper validations and error responses are implemented.
- **MongoDB Integration:** Uses Mongoose to connect to a MongoDB database.
